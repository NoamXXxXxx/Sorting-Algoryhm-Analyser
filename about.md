# About

Sorting Algorithm Analyzer

Sorting Algorithm Analyzer is a Python-based desktop application designed to visualize and analyze sorting algorithms.

The application provides an interactive environment where users can observe how different sorting algorithms work, examine their execution process, and compare their performance.

# Purpose

The project was created to explore sorting algorithms in practice and better understand their behavior, efficiency, and implementation.

It combines algorithm visualization, performance analysis, and database management in a single application.

Functionality

- Algorithm Visualization — displays sorting operations using animated vertical bars.
- Custom Parameters — allows users to configure array size and visualization speed.
- Performance Statistics — measures execution time and counts sorting operations.
- Customization — provides interface themes and visualization settings.
- Result Storage — saves execution results in an SQLite database.
- Database Management — allows users to review and delete saved records.
